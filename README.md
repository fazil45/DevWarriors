# DevWarrior

DevWarrior is a competitive full-stack backend coding platform where developers solve real-world software engineering challenges instead of traditional algorithmic problems. Rather than focusing on data structures and algorithms, DevWarrior tests practical backend development skills by asking users to build production-ready APIs, authentication systems, middleware, database integrations, and other real-world features.

Creators can design coding contests by defining custom backend challenges, test cases, scoring criteria, and AI-powered evaluation prompts. Developers write and submit code directly on the platform, where each submission is securely executed inside isolated containers and automatically evaluated for correctness, functionality, code quality, and adherence to project requirements.

The platform provides live leaderboards, real-time rankings, detailed submission feedback, and contest analytics to create an engaging competitive environment. With Redis-powered real-time updates, secure code execution, and scalable architecture, DevWarrior delivers a smooth experience for both challenge creators and participants.

# Key Features

*  Authentication and authorization challenges
*  Secure sandboxed code execution
*  AI-powered submission evaluation
*  Real-time contest leaderboards
*  Detailed scoring and feedback
*  Custom challenge creation for creators
*  Automated test case validation
*  Live contest management
*  Developer performance analytics
*  Backend-focused real-world problem solving

# Tech Stack

* **Frontend:** Next.js, React, TypeScript, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL, Prisma ORM
* **Caching & Realtime:** Redis
* **Authentication:** JWT, bcrypt
* **Code Execution:** Piston (Docker-based sandbox)
* **AI Evaluation:** LLM-powered scoring system
* **Deployment:** Docker, Kubernetes, GitHub Actions

DevWarrior bridges the gap between competitive programming and real-world software engineering by providing an environment where developers can practice, compete, and showcase practical backend development skills that closely resemble actual industry tasks.
